01 AI provider

Pick a provider and paste its key. QuizKey speaks three API dialects natively: OpenAI Chat Completions (also OpenRouter, OmniRoute, LM Studio, Ollama, Azure, vLLM…), Google Gemini and Anthropic Claude. The key is stored in chrome.storage.local only and is sent solely to the configured endpoint.

06 Local files (file://)

QuizKey can capture local quiz files out of the box, but typing and the on-page overlay need your permission for local files. Grant it here with one click, then re-open (or reload) the file. Note: Chrome only shows its own "Allow access to file URLs" toggle (under chrome://extensions → QuizKey → Details) when the extension declares URL permissions. If you don't see it, this button is the equivalent official path.
