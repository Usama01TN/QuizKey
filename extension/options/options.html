05 Local files (file://)

QuizKey can capture local quiz files out of the box, but typing and the on-page overlay need your permission for local files. Grant it here — one click, then re-open (or reload) the file. Note: Chrome only shows its own "Allow access to file URLs" toggle (under chrome://extensions → QuizKey → Details) when the extension declares URL permissions — if you don't see it, this button is the equivalent official path.
